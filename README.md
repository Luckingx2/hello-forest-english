# 곰돌이 영어숲 · Hello Forest

그림과 영어 소리로 함께 노는 한국어 안내 영어 게임입니다. 빌드나 설치 없이 실행하는 정적 HTML/CSS/JavaScript 앱입니다.

## 실행

저장소 루트에서 `python3 -m http.server 8000`을 실행한 뒤 http://localhost:8000 을 엽니다. 진입 파일은 `index.html`입니다. `app.js`, `style.css`, `assets/forest-bear.webp`를 함께 배포해야 합니다. 모든 앱 자산 경로는 상대 경로이며 GitHub Pages의 저장소 하위 경로에서도 사용할 수 있습니다.

## GitHub Pages 배포

이 폴더의 내용을 저장소 루트에 넣습니다. GitHub Pages에서 사용할 브랜치의 `/ (root)`를 배포 대상으로 선택합니다. `.nojekyll` 파일이 포함되어 있습니다. 빌드 명령, npm 설치, 환경 변수, 비밀 키, 서버, 데이터베이스가 필요하지 않습니다. GitHub Actions로 배포할 경우 같은 루트 정적 파일을 Pages 아티팩트로 업로드할 수 있습니다.

사이트를 공개하면 URL을 아는 사람이 로그인 없이 게임을 열 수 있습니다. 저장소 공개 여부와 Pages 공개 여부는 계정 및 저장소 설정에 따라 별도로 확인해야 합니다.

## 놀이

기존 그림 놀이와 새 문장 말하기를 함께 제공합니다.

- 기존 동물 찾기, 과일·색깔 소풍, 동작 따라 하기: 15개 낱말, 한 판 여섯 번
- 기존 단계: 씨앗(그림 + 두 선택지), 새싹(소리 + 두 선택지), 나무(소리 + 세 선택지)
- 문장으로 말해요: 소풍에서 고르기, 동물과 놀이, 고양이 위치, 소풍 기분, 과일 세기·나누기, 비 오는 날 준비의 여섯 장면
- 친구와 이야기해요: “곰 친구와 놀아요”, “소풍 과일 가게”에서 질문 네 번에 자기 문장으로 대답
- 새 단계: 같이 말하기(전체 문장 듣고 따라 하기), 혼자 말하기(그림과 질문부터), 이야기 늘리기(이유·계획·두세 문장)
- 새 말하기 단계는 기본 2단계이며 기존 그림 놀이 단계와 별도로 저장됩니다. 기존 스티커와 복습 기록은 유지합니다.
- 2·3단계에서는 예시 답을 화면과 자동 음성에서 숨깁니다. 원하는 때 “예시 문장 보기·듣기”로 확인합니다.
- 질문 다시 듣기, 질문·예시 천천히 듣기, 한국어 도움, 그림 선택, 보호자와 역할 나누기
- 예시는 유일한 정답이 아닙니다. 자기 생각을 다르게 말해도 됩니다.
- 시간 제한 없이 “말했어요”로 스스로 완료 표시하고 다음 질문으로 이동합니다.
- 듣기만 하거나 “다음에 해요”로 건너뛰어도 벌점 없이 놀이 스티커를 받습니다.
- 보호자 목소리 선택, 움직임 줄이기, 기존 소풍 주제 선택, 기록 초기화 확인

## 소리와 접근성

브라우저 `speechSynthesis`와 기기의 영어·한국어 목소리를 사용합니다. 놀이 또는 소리 버튼을 눌러 재생을 시작합니다. 보호자 설정에서 목소리를 고르고 테스트할 수 있습니다. 지원 여부와 발음은 기기마다 다릅니다. 음성이 없거나 실패하면 그림 힌트와 보호자 읽기 안내를 보여 줍니다. 녹음, 음성 인식, 발음 평가는 하지 않습니다. 말하기 완료는 아이나 보호자가 누르는 수동 표시이며, 실제 발음을 감지하거나 정답으로 판정하지 않습니다. 영어 목소리는 있지만 한국어 목소리가 없으면 한국어 음성만 건너뛰며 화면 안내와 영어 재생은 유지합니다. 역할 나누기에서는 보호자가 친구의 질문을 읽고 아이가 자기 문장으로 대답합니다. 이 모드에서는 질문을 자동 재생하지 않으며 필요한 때 재생 버튼을 누를 수 있습니다.

큰 기본 HTML 버튼, 키보드 포커스 표시, 한국어 접근성 레이블, 움직임 줄이기 설정과 320px부터의 반응형 스타일을 포함합니다. 실제 배포 뒤 휴대폰과 데스크톱에서 조작과 음성을 확인해 주세요.

## 데이터와 개인정보

게임 자체는 계정, 마이크, 카메라, 광고, 분석 추적, 외부 API를 사용하지 않습니다. 이름이나 생일 등 개인정보를 입력하지 않습니다. 스티커, 다시 만날 낱말, 설정은 각 브라우저의 `localStorage`에만 저장됩니다. 다른 기기와 동기화하지 않으며 보호자 설정에서 지울 수 있습니다. 도메인이 바뀌면 기존 기록은 자동 이동하지 않습니다. 호스팅 제공자가 처리하는 일반 접속 정보는 제공자 정책을 따릅니다.

## 검사

Node.js가 있으면 외부 패키지 설치 없이 `node --check app.js` 및 `node tests/game-runtime.cjs`, `node tests/speaking-runtime.cjs`, `node tests/audio-regression.cjs`, `node tests/speaking-stress.cjs`를 실행할 수 있습니다.

315개 모의 세션과 1,890개 라운드에서 선택지 유효성, 정답 위치 변화, 여섯 라운드 완료, 힌트, 저장과 초기화, 음성 실패 대체 화면을 검사합니다. 새 말하기 검사에서는 3단계 문장 말하기와 2개 이야기의 보호자 역할 모드 조합, 숨긴 예시의 화면·음성·상태 누출 방지, 명시적 예시 열기, 그림 선택, 수동 완료/건너뛰기, 연속 클릭 방지, 느린 재생, 다시 시작/홈 이동, 키보드 포커스 유지, 기존 저장 기록 이관을 검사합니다. 추가 스트레스 검사는 180개 세션과 840개 말하기 차례를 확인합니다. 한국어 음성이 없는 경우 등 음성 회귀 검사도 포함합니다. 음성 큐 및 WebMCP 등록은 모의 환경에서 검사합니다. 실제 브라우저 렌더링, 터치·키보드, 기기 음성 품질, 실환경 WebMCP 지원을 검증하는 테스트는 아닙니다.

## 포함 파일

- `index.html`: 진입 화면
- `app.js`: 놀이·음성·설정 로직
- `style.css`: 반응형 화면 및 동작 스타일
- `assets/forest-bear.webp`: 이 게임을 위해 생성한 숲속 곰 그림
- `tests/game-runtime.cjs`: 기존 세 가지 놀이 런타임 검사
- `tests/speaking-runtime.cjs`: 따라 말하기·역할 놀이 런타임 검사
- `tests/audio-regression.cjs`: 음성 큐·한국어 음성 부재 회귀 검사
- `tests/speaking-stress.cjs`: 말하기·역할 놀이·오디오 실패 조합 스트레스 검사
- `.nojekyll`: GitHub Pages 정적 배포용

이 이관용 파일에는 기존 호스팅 설정, Git 이력, 자격 증명, 사용자 놀이 기록을 포함하지 않았습니다.

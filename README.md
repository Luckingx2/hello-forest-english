# 곰돌이 영어숲 · Hello Forest

그림과 영어 소리로 함께 노는 한국어 안내 영어 게임입니다. 빌드나 설치 없이 실행하는 정적 HTML/CSS/JavaScript 앱입니다.

## 실행

저장소 루트에서 `python3 -m http.server 8000`을 실행한 뒤 http://localhost:8000 을 엽니다. 진입 파일은 `index.html`입니다. `app.js`, `style.css`, `assets/forest-bear.webp`를 함께 배포해야 합니다. 모든 앱 자산 경로는 상대 경로이며 GitHub Pages의 저장소 하위 경로에서도 사용할 수 있습니다.

## GitHub Pages 배포

이 폴더의 내용을 저장소 루트에 넣습니다. GitHub Pages에서 사용할 브랜치의 `/ (root)`를 배포 대상으로 선택합니다. `.nojekyll` 파일이 포함되어 있습니다. 빌드 명령, npm 설치, 환경 변수, 비밀 키, 서버, 데이터베이스가 필요하지 않습니다. GitHub Actions로 배포할 경우 같은 루트 정적 파일을 Pages 아티팩트로 업로드할 수 있습니다.

사이트를 공개하면 URL을 아는 사람이 로그인 없이 게임을 열 수 있습니다. 저장소 공개 여부와 Pages 공개 여부는 계정 및 저장소 설정에 따라 별도로 확인해야 합니다.

## 놀이

- 동물 찾기, 과일·색깔 소풍, 동작 따라 하기의 세 가지 놀이
- 15개 영어 낱말, 한 판 여섯 번
- 씨앗: 그림 힌트와 두 선택지 / 새싹: 소리와 두 선택지 / 나무: 소리와 세 선택지
- 다시 듣기, 한국어 안내, 부드러운 힌트, 선택적인 복습과 스티커
- 보호자 목소리 선택, 움직임 줄이기, 주제 선택, 초기화 확인

## 소리와 접근성

브라우저 `speechSynthesis`와 기기의 영어·한국어 목소리를 사용합니다. 놀이 또는 소리 버튼을 눌러 재생을 시작합니다. 보호자 설정에서 목소리를 고르고 테스트할 수 있습니다. 지원 여부와 발음은 기기마다 다릅니다. 음성이 없거나 실패하면 그림 힌트와 보호자 읽기 안내를 보여 줍니다. 녹음이나 발음 평가는 하지 않습니다.

큰 기본 HTML 버튼, 키보드 포커스 표시, 한국어 접근성 레이블, 움직임 줄이기 설정과 320px부터의 반응형 스타일을 포함합니다. 실제 배포 뒤 휴대폰과 데스크톱에서 조작과 음성을 확인해 주세요.

## 데이터와 개인정보

게임 자체는 계정, 마이크, 카메라, 광고, 분석 추적, 외부 API를 사용하지 않습니다. 이름이나 생일 등 개인정보를 입력하지 않습니다. 스티커, 다시 만날 낱말, 설정은 각 브라우저의 `localStorage`에만 저장됩니다. 다른 기기와 동기화하지 않으며 보호자 설정에서 지울 수 있습니다. 도메인이 바뀌면 기존 기록은 자동 이동하지 않습니다. 호스팅 제공자가 처리하는 일반 접속 정보는 제공자 정책을 따릅니다.

## 검사

Node.js가 있으면 외부 패키지 설치 없이 `node --check app.js` 및 `node tests/game-runtime.cjs`를 실행할 수 있습니다.

315개 모의 세션과 1,890개 라운드에서 선택지 유효성, 정답 위치 변화, 여섯 라운드 완료, 힌트, 저장과 초기화, 음성 실패 대체 화면을 검사합니다. 음성 큐 및 WebMCP 등록은 모의 환경에서 검사합니다. 실제 브라우저 렌더링, 터치·키보드, 기기 음성 품질, 실환경 WebMCP 지원을 검증하는 테스트는 아닙니다.

## 포함 파일

- `index.html`: 진입 화면
- `app.js`: 놀이·음성·설정 로직
- `style.css`: 반응형 화면 및 동작 스타일
- `assets/forest-bear.webp`: 이 게임을 위해 생성한 숲속 곰 그림
- `tests/game-runtime.cjs`: 외부 패키지 없는 런타임 검사
- `.nojekyll`: GitHub Pages 정적 배포용

이 이관용 파일에는 기존 호스팅 설정, Git 이력, 자격 증명, 사용자 놀이 기록을 포함하지 않았습니다.
